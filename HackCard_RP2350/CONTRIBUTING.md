# Contributing

Test firmware and library changes on a real HackCard RP2350.

- Board: Generic RP2350, Flash Size 2MB (no FS), USB Stack Pico SDK
- Drivers live in `library/HackCard_RP2350`
- Include `<HackCardRP2350.h>`, not the ESP32 `<HackCard.h>`
- Keep personal contact details out of commits; `user_config.h` should stay on the demo identity

Lab features stay limited to tags and computers you are allowed to use. See [docs/ethics-and-authorized-use.md](docs/ethics-and-authorized-use.md).
