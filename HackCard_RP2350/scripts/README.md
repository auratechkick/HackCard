# Install the HackCard RP2350 Arduino library

Copies `library/HackCard_RP2350` into your Arduino libraries folder.
It does not replace the ESP32 `HackCard` library. The include is `<HackCardRP2350.h>`.

```powershell
cd D:\HackCard_RP2350_Github\HackCard_RP2350\scripts
.\install-library.ps1
```

Restart Arduino IDE if it was already open. Examples appear under **File → Examples → HackCard RP2350**.
