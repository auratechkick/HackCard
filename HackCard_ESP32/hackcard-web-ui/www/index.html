NFC Reader

PN532 front-end — scan and program physical tags; HackCard does not act as a scannable NFC card

Checking PN532…

What HackCard NFC is

  • Reader / writer — talks to tags you place on the antenna
  • Not tag emulation — phones cannot “tap HackCard” like a payment or access card
  • External tags only — bring NTAG stickers, cards, or fobs to the PN532 pad
  • Lab tools — erase, clone, Classic dump need operator PIN (authorized use)

Tag types this reads

  • NTAG213 / 215 / 216 — common phone-tap stickers (NDEF URLs, vCard)
  • MIFARE Ultralight — Type 2, read / write / dump
  • ISO14443A Type 2 — UID, Tag Info, page dump, NDEF write
  • MIFARE Classic 1K / 4K — UID + lab dump/clone (needs known keys)

Unsupported here: ISO15693, FeliCa, EMV payment cards (secure element), most hotel key formats without keys.

Tip: center the tag on the PN532 coil, hold still 1–2 seconds, wait for the ready chime.

DuckyScript Payloads

Edit, upload, or save scripts to /payloads/ on SD or flash. Commands: OS, DELAY, STRING, GUI, ACTION, MOUSEMOVE, …

How to test DuckyScript (step-by-step)
  1. Set Lab PIN (sidebar or mobile) — same PIN as Settings → Lab PIN.
  2. Connect HackCard USB-C data port to a Windows/macOS/Linux PC (USB host).
  3. On the PC, open Notepad — leave it focused. Status bar should say host connected.
  4. Click New (default script loads). Run on USB host does not require save — it runs the editor text directly.
  5. Choose target OS (Windows for the default template), click Run on USB host — after ~1.5 s the PC should type “Hello from HackCard!”.
  6. Use Save to device to keep scripts on flash; if that fails, set Arduino partition to partitions.csv and run Tools → ESP32 Sketch Data Upload, or use Save to SD.
